## Installation
1. Clone this repo with `git clone`
2. Open this repo in an IDE (e.g., Visual Studio, Cursor, etc.)
3. Open Terminal and navigate to frontend with `cd frontend`
4. Install packages with `npm install`
5. Preview the website with `npm run dev`
6. See the preview by going to `http://localhost:3000`
